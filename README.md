# vmarsocci.github.io — v0.3

A lightweight academic website inspired by compact researcher homepages rather than portfolio/marketing templates.

## Structure
- `index.html` — compact homepage with profile, latest news and selected publications
- `news.html` — full news archive
- `publications.html` — broader publication / software list
- `resume.html` — public academic resume
- `talks.html` — invited talks, keynotes and seminars
- `assets/profile.jpg` — profile photo
- `assets/style.css` — shared styling

## Deploy
Copy/replace these files at the root of the `VMarsocci.github.io` repository and commit to `main`. GitHub Pages should redeploy automatically.
