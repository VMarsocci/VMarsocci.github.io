# Valerio Marsocci — personal academic website v0.2

A lightweight static academic website for GitHub Pages.

## What changed from v0.1

- Much closer to the structure and content of the previous Google Site.
- Classic academic navigation: Home / News / Publications / Resume / Talks / Blog.
- Simpler and greener visual design.
- Removed the large marketing-style hero, sales-like project cards and promotional wording.
- Added current 2026 items while preserving older site content.
- Public resume intentionally excludes private phone number and home address.

## Commit/update

If the repository is already `VMarsocci.github.io`:

1. Delete/replace the old site files with the contents of this folder.
2. Commit all changes to `main`.
3. GitHub Pages should automatically redeploy.

No build command, package manager or framework is required.

## Main files

- `index.html` — homepage
- `news.html`
- `publications.html`
- `resume.html`
- `talks.html`
- `blog.html`
- `assets/styles.css` — all styling
